# Public source scope

This repository is a clean source snapshot with no private commit history.
It preserves the app, core algorithms, controller boundaries, tests, assets,
AGPL license, and third-party notices. Personal facts, private deployment notes,
live policies, credentials, runtime records, and private schedule registrations
are excluded.

## Bundled admission helpers

Four small source-governance helpers are included with the core. Imports use the
bundled package, not another installation in a user's home directory. The public
owner identifier is `local-owner`. Missing configuration admits no personal
sources; it does not silently authorize a new machine or import private grants.

The optional report adapter ships with an empty job allowlist. There is no
pre-authorized report destination or schedule. The private per-person memory
translation catalogue is removed; generic rendering remains.

## Optional operator integrations

Some controlled repair, release qualification, memory management, task routing,
and report-delivery paths were designed for a separate local agent environment.
Their required external adapters include a backup manager, memory review center,
memory writer, and native task/authorization channels. Their code references and
synthetic tests remain visible for inspection, but this snapshot does not bundle
that separate environment or grant its permissions.

These operations require deliberate integration work and fresh local
qualification. A missing adapter, grant, receipt, or tool must leave the action
unavailable. Do not weaken a gate merely to make a local demonstration pass.

## Validation limits

The portable CI checks, full operator integration tests, application build,
installation, and natural usefulness are different stages. Public CI does not
claim complete production acceptance. No private test receipt or installed-app
state is reused as proof for this snapshot.

The repository contains historical design documents where useful. They describe
source and design, not promises that every workflow is enabled or accepted.

## External content lists

The compiled external domain-list Bloom snapshot is not distributed. Built-in
local domain and text safeguards remain. The optional generator in
`core/tools/update_adult_policy_snapshot.py` can rebuild a local snapshot from
its explicitly listed upstream sources. Review each upstream license before
redistributing generated data; the source lists have separate terms.

The report recovery adapter is deliberately unconfigured. It contains no
original disk UUID or private archive destination and refuses use until a local
operator supplies and qualifies their own adapter. Manual authorization still
requires the operator's native runtime registration; bundling its code does not
provide that registration.
