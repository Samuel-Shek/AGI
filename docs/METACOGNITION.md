# 思考与反思

帮助本人看清思考方式、发现有依据的停滞并调整，是 AGI 的首要用户价值。提示是可以纠正的假设；“尚未发现”也是有效结果。界面提供首页最新提醒、独立页面、具体引文与来源标识、有帮助、判断不准确、暂不提醒和关闭。

## 范围与运行

沿用批评系统已登记、经过本机账户归属验证的 Codex、Claude Code、Hermes 主对话；读取最近14天的用户问题及 AI 回答。排除子代理、元指令、工具输出，引用与示例保留材料身份，凭据在本机先拦截。Hermes 远端身份必须命中既有 owner 映射；未登记或身份不明不读正文。现有 Codex 登录通道进行分析，不切换供应商，不调用 Jev，不写共享长期记忆，不触发修复或决策。

既有五分钟控制器按变化增量读取，独立本机记录位于 core/data/reflection/reflection.sqlite。每批最多五个讨论、连同系统要求输入最多64KiB；长讨论先分批保存摘要与精确引文，未完整读取不能成为提醒依据。窗口仅限制输入时间，已生成的功能记录和更正历史保留；不删除原始来源。来源数量、身份缺口和待处理讨论在界面展示，不能声称全平台全历史覆盖。

两类分析共用原串行模型锁、账户限制、调用台账和失败退避；两类均待处理时轮换，失败也让出下一次机会。反思调用另行登记 request、输入字节与状态，可关联原台账中的真实用量。超时或结果不明保持占用，不自动退款。全局暂停、本功能关闭、实际读取、模型启动、发布及通知认领共用短控制边界；等待模型或系统通知不占用该边界。授权代次变化或停止后恢复都丢弃旧任务的晚到结果；暂停页面只读缓存，不重新打开来源。

未变的输入已有未知、进行中或校验失败记录时，不再次提交。旧记录仅从其精确私有请求目录核对输入版本，不采用旧结果，不推进未完成水位或修改旧用量；无法安全核对则显示缺口并暂缓分析。查重在原模型锁内、预算预留前再次执行。未变失败批可让出位置给其他讨论，每批限制保持；实质新材料才可形成新的输入。空闲轮不能证明连接或账户恢复，不清空原失败计数与退避；原延迟和账户限制不变。

## 证据与纠正

模型须区分直接陈述、观察模式与候选假设；先检查正常研究、新信息、复杂问题、现实限制及 AI 漏答。至少两条独立本人陈述才能形成候选，分片不能算独立依据。三段包含第一人称问题、线索到模式的关系、替代解释、反证条件及中立区分问题。每条引文在发布前逐字核对角色、归属与当前来源版本，语义判断仍可能出错。

相同证据不重复通知。新进展保留旧假设原始依据供复核，反证可撤回旧判断并写更正历史。用户指出不准确即撤下；暂不提醒保存抑制状态，重启保留，不自动恢复。所有已暂停或指出误判的问题摘要优先带入后续批次，不受最近30条限制；超过输入上限时暂缓全部新提醒并显示缺口。更新或撤回前保存旧版本字段与引文。来源变化或不可核对时撤下对应判断。Mac 通知只提示到 AGI 查看，不在锁屏展示私人原话；发出请求与实际显示分别验收。

## 固定接口

超过14天的证据在回源读取前拒绝；新增进展尚未读完或整段来源版本改变时，先撤下对应判断并保存旧版本。新本人或助手证据才能更新，仅重建派生索引不重复通知。引用解析升级保留旧派生记录供核对，按原增量机制重建。通知启动前先保存认领；提交不明保持未知，不自动重发；认领前重新核对反馈状态和判断版本。

`python -B -m activity_mvp.reflection.cli` 只接受 status、list、detail、configure、analyze、feedback。配置及反馈通过 --payload-stdin 传入对象；只读命令不创建数据库、不迁移、不启动模型。analyze 仅请求既有控制器下一次处理新增讨论。configure 仅接受布尔 enabled；feedback 仅接受当前 id、整数 revision 与 helpful/inaccurate/mute。无任意命令、记忆或权限修改入口。

默认数据库缺失时关闭；本次部署按用户批准计划启用。关闭可在“思考与反思”页使用“关闭反思分析”，全局暂停沿用已有控制入口。恢复只在最新源码撤本次差异，重做配套构建与固定控制器验收，保留原始数据、新增记录、后续提交与并行改动，禁止旧数据库覆盖。

## 验收层次

固定程序检查、真实模型虚构样本、系统隔离、安装版界面、通知与自然运行分别记录。虚构样本、用户点“有帮助”或感到被说中不证明判断正确。至少七天且三次独立自然使用案例后，结合来源、用户纠正及可验证下一步评估；未到条件不认证元认知提升。共享规则入口同步与各客户端新会话实际遵从也分别取证。

未知前缀之后的实际新范围可继续分批读取，单独保存尾部进度，不推进原连续读取水位；这些讨论保持不完整，不能发布其假设。已读完尾部的缺口不占用其他讨论的五个输入名额。缺失范围全部超出十四天后，重新建立当前窗口的完整语境，旧未知调用仍保留。

未确认结果的准入按已提交的实际发言范围持久核对，绑定原消息身份、角色、可见内容和分段起点。排序、摘要、抑制要求和解析编号变化不构成新材料；旧解析记录只从保留表精确恢复，无法核对时暂停分析。此核对在既有模型锁内、预留预算之前再次执行。
