# Project direction

The public interface is the [local browser workbench](../web/README.md). Its current scope covers reviewing questions and processing records, inspecting their evidence and saving local drafts. The bundled fictional dataset provides a reproducible entry point for contributors.

The Python Core also contains experimental reflection, source admission and bounded improvement logic. Claims about everyday usefulness depend on observed outcomes in a separately authorized local setup. See the [source scope](PUBLIC_SOURCE_SCOPE.md) for the boundaries covered by public checks.
