# 后台运行与控制台

现有登录服务继续独立运行。App 不负责启动这些服务，普通关闭窗口或“关闭控制台”不会停止后台。暂停、恢复、停止仍沿原控制入口，未保存、保存中或结果不明的草稿阻止退出。

`--background-maintenance` 是原发布协议使用的轻量启动模式：无窗口、无菜单栏、无普通页面轮询，只保留更新退出协调。重复的后台打开也不激活控制台；用户主动打开才显示窗口。当前 macOS 的 LaunchServices 实测后台 reopen 不激活且带 `rsto: 'no  '`，前台打开会先激活。代码同时核对这两个信号；其他系统版本仍需实际验证。

记忆候选使用与执行队列一致的既有授权边界。调查来源不自动取得执行授权；隐藏的历史行保持原样。入队只处理同一身份的冲突，以保存点撤回本次未完成写入，不吞掉其他约束错误。结果不明的既有及本轮执行均保留待核对状态，不重放。

记忆阶段失败时，本轮标为部分失败，停止依赖它的分析、主动调查和修复。独立来源扫描、已有事件的复盘记录及通知可继续：它们只使用自身原来源/事件，不消费本轮记忆结果；原权限与暂停检查继续生效。通知提交后的状态也计入整轮结果。

普通反思、日常完成和自行恢复不提醒。必要事项沿原编号/版本去重；来源、分析、记忆连续失败至少三次后使用固定无正文提示。原事件详情与后台检查状态保留在现有入口。已知提交前取消可以恢复排队；真正未知送达不重发。旧对外通知仅核对已尝试的原请求，未发送的普通完成保留本地历史。

任务收尾后台也遵守同一规则：完成、取消及由执行者处理的普通技术等待只保留本地事件。本人待决定、原创建/发送结果未知以及已核实恢复条件但尚未安排执行的事项沿原通知队列提醒；使用事项编号、版本和固定原因说明影响、已尝试措施及所需决定，不要求打开控制台，不暴露私人任务正文。原已请求、拒绝和未知送达记录保持原样。

健康判断必须同时核对进程、心跳和实际任务结果；队列为空、进程存在都不能证明有效覆盖。失效授权目录不自动迁移或重新授权。源码、配套安装、无界面运行、登录/唤醒及七天三次自然帮助分别验收。测试日志和本机发布回执不代表自然价值已经实现。

分析按原家族保留未解除的阻碍：另一家族成功、无新任务或完成轮询均不能清除未知输入。来源轮转未检查到旧故障也不算恢复；准备超时保留部分失败，不写成本轮完整完成。连续受阻的同一阶段只沿原通知队列提醒一次，原因码变化不会绕过未知送达去重。记忆异常仅记录程序模块相对位置、行号、异常类和白名单原因码，不保存异常正文、参数、局部变量或用户路径。

已授权的目录迁移使用内部操作者入口 `document_root_migration`，无新增网络或用户命令。精确计划绑定原根集合、版本、暂停状态、路径身份和显示规则；一次数据库事务停用旧根、新增新根及文档专属子树排除，保留原文件、事件、版本、覆盖缺口和旧根检查点。子树排除在读取前按完整规范路径及等价大小写/Unicode拼写检查，不影响提到该路径的反馈或通知。

迁移回执与数据库授权一起提交；登记文件随后投影。中断时版本不匹配会关闭文件读取；原回执只能在授权、目录、规则均未改变时修复登记文件，不能重建或重放授权。提交结果不明须从新只读连接核对同一回执，不清理历史。现有后台用新授权代次淘汰旧工作线程，再沿原入口重建覆盖。

安装新读取程序只添加空表，活动数据仍保持版本 32，使配套安装失败时原程序可以接回；安装完成验收后，迁移事务再一次性启用排除并升至版本 33。数据库版本 33 表示文档排除是必需权限约束。旧核心必须拒绝读取该版本；不得降低版本号或用旧数据库恢复运行。发布失败可保留现有数据并恢复兼容程序；迁移后如需撤回程序，必须先验证恢复程序仍执行这些排除，或明确停用本次新增根且保留历史，不能让不识别排除的旧核心继续工作。自然登录、唤醒和三次帮助仍分别等待真实证据。
