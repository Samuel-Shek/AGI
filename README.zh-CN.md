# AGI

[English](README.md)

AGI 是一个实验性的 macOS 个人工作回顾工具。它把文件变化、需要处理的事项、
来源与权限检查、改进候选放进同一个原生应用，底层由 Python 处理，
由 Personal AI Monitor 演进而来。

AGI 是项目名称，不代表已经实现通用人工智能。自动修复和元认知提醒是否长期有用，
仍需要真实使用验证。

## 能做什么

- 查看近期活动、文件变化、待处理事项和系统状态。
- 核对文件追踪的覆盖情况，保留无法判断的修改归属。
- 检查资料来源、读取授权、撤销状态和隐私过滤结果。
- 在另行配置和授权后，尝试对话反思与受控改进。

屏幕采集需要明确开启。读取对话、调用模型、写入记忆和修改软件分别控制权限。
没有来源配置时，不接纳任何个人资料。

## 如何开始

需要 macOS、Python 3.12 或更高版本，以及 Swift 5.9 或更高版本。
先看[开发与安装说明](docs/INSTALL.md)，使用独立的数据目录。
当前发布源码，不提供已签名、公证的安装包。

源码包含应用、后台、测试和浏览器扩展。核心导入需要的通用来源检查代码已包含在仓库内。
原有记忆、调度、备份和发布流程中的部分接口仍依赖使用者另行配置；
缺少依赖或授权时，相关操作应保持关闭。
详见[公开源码范围](docs/PUBLIC_SOURCE_SCOPE.md)。

公开版不包含私人配置、聊天记录、截图、运行数据库、凭据或旧部署历史。
测试和问题反馈请使用虚构材料。
