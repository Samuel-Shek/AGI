# PSI web workbench

Run `python3 -B web/psi_sync_center.py` from the repository root and open the loopback address printed in the terminal. The default session uses a bundled fictional dataset. The Python server, browser assets and synthetic tests are all in this directory.

The [startup guide](../docs/INSTALL.md) covers persistent example drafts, alternate ports and existing local Core integrations. The [example data](tests/fixtures/demo.json) can also be used with `--fixture`.
