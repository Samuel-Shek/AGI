# Code of Conduct

This project expects respectful, privacy-preserving collaboration.

Do not use Personal AI Monitor to normalize hidden monitoring, employee surveillance,
classroom monitoring, or collection of another person's activity without
informed consent.

Issues, pull requests, discussions, and examples must not include private user
data, secrets, screenshots, logs, raw keyframes, OCR text, SQLite databases, HA
packages, or real activity records.

Security and privacy issues should be reported privately according to
`SECURITY.md`.
